# Time Machine

Chrome extension that changes speed of web games

## Usage

1. Clone this repository
   ```bash
   git clone https://github.com/muyao/time-machine.git
   ```
2. Go to `chrome://extensions`
3. Click `Load unpacked`
4. Select `time-machine/chrome_extension`. This should import the extension into Chrome.
5. Open the extension's options page and input the dilation factor. `1` = same speed `2` = double speed `0.5` = half speed
6. Reload the website you want to use this on. If it still doesn't work, close and reopen that tab.
